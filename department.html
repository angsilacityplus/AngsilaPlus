ส่วนราชการ

รวมกอง/สำนักทั้งหมดของเทศบาลเมืองอ่างศิลา คลิกที่แต่ละหัวข้อเพื่อดูรายละเอียด

สำนักปลัดเทศบาล

งานบริหารทั่วไป / งานทะเบียนราษฎร

ดูแลงานบริหารทั่วไปของเทศบาล งานสารบรรณ งานทะเบียนราษฎรและบัตรประชาชน งานป้องกันและบรรเทาสาธารณภัย และงานนิติการ

  • รับเรื่องราวร้องทุกข์ / งานสารบรรณกลาง
  • งานทะเบียนราษฎร ย้ายที่อยู่ แจ้งเกิด-ตาย
  • งานป้องกันและบรรเทาสาธารณภัย
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 101

กองยุทธศาสตร์

งานแผนงาน / งบประมาณ / วิเคราะห์นโยบาย

จัดทำแผนพัฒนาท้องถิ่น ควบคุมงบประมาณประจำปี ติดตามและประเมินผลโครงการต่าง ๆ ของเทศบาล

  • จัดทำแผนพัฒนาเทศบาล / เทศบัญญัติงบประมาณ
  • ติดตามและประเมินผลโครงการ
  • งานสารสนเทศและสถิติของเทศบาล
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 102

กองสาธารณสุข

งานสาธารณสุขและสิ่งแวดล้อม

ดูแลงานส่งเสริมสุขภาพ ควบคุมโรคติดต่อ งานสุขาภิบาลและอนามัยสิ่งแวดล้อม รวมถึงงานจัดเก็บขยะมูลฝอยในเขตเทศบาล

  • งานเก็บขนขยะมูลฝอย / สิ่งปฏิกูล
  • งานควบคุมโรคติดต่อ / ฉีดวัคซีนสัตว์
  • งานสุขาภิบาลอาหารและตลาด
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 103

กองคลัง

งานการเงิน / บัญชี / จัดเก็บรายได้

รับผิดชอบงานการเงิน การบัญชี การจัดเก็บภาษีและรายได้ของเทศบาล งานพัสดุและจัดซื้อจัดจ้าง

  • ชำระภาษีที่ดินและสิ่งปลูกสร้าง / ภาษีป้าย
  • งานพัสดุและจัดซื้อจัดจ้าง
  • งานเบิกจ่ายและงบการเงิน
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 104

กองการเจ้าหน้าที่

งานบุคลากรและสวัสดิการพนักงาน

ดูแลงานบรรจุแต่งตั้ง สรรหาบุคลากร งานสวัสดิการและการพัฒนาบุคลากรของเทศบาล

  • งานสรรหาและบรรจุแต่งตั้ง
  • งานสวัสดิการและสิทธิประโยชน์พนักงาน
  • งานฝึกอบรมและพัฒนาบุคลากร
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 105

กองช่าง

งานโยธา / ไฟฟ้าสาธารณะ / ผังเมือง

ดูแลงานก่อสร้างและซ่อมบำรุงถนน ไฟฟ้าสาธารณะ ระบบระบายน้ำ และงานผังเมืองในเขตเทศบาล

  • ซ่อมแซมถนน / ไฟส่องสว่างสาธารณะ
  • ดูแลระบบระบายน้ำ ป้องกันน้ำท่วมขัง
  • ออกแบบและควบคุมงานก่อสร้าง
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 106

กองการศึกษา

งานโรงเรียน / ศูนย์พัฒนาเด็กเล็ก / กีฬา

ดูแลศูนย์พัฒนาเด็กเล็กและโรงเรียนในสังกัดเทศบาล งานส่งเสริมศาสนา ศิลปวัฒนธรรม และการกีฬาในท้องถิ่น

  • ศูนย์พัฒนาเด็กเล็กในสังกัดเทศบาล
  • งานส่งเสริมกีฬาและนันทนาการ
  • งานทำนุบำรุงศาสนาและวัฒนธรรมท้องถิ่น
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 107

กองสวัสดิการสังคม

งานสงเคราะห์ / เบี้ยยังชีพ / ชุมชน

ดูแลงานสงเคราะห์ผู้สูงอายุ ผู้พิการ และผู้ด้อยโอกาส งานเบี้ยยังชีพ และงานพัฒนาชุมชนในเขตเทศบาล

  • ขึ้นทะเบียนเบี้ยยังชีพผู้สูงอายุ / ผู้พิการ
  • งานพัฒนาชุมชนและกองทุนชุมชน
  • งานสงเคราะห์ผู้ด้อยโอกาส
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 108

สถานธนานุบาล

โรงรับจำนำเทศบาล (สวัสดิการประชาชน)

ให้บริการรับจำนำทรัพย์สินแก่ประชาชนในอัตราดอกเบี้ยต่ำ เป็นสวัสดิการช่วยเหลือด้านการเงินเบื้องต้นแก่ประชาชนในพื้นที่

  • รับจำนำทองรูปพรรณ / เครื่องใช้ไฟฟ้า
  • อัตราดอกเบี้ยตามระเบียบเทศบาล
หัวหน้าส่วน: (อยู่ระหว่างปรับปรุงข้อมูล) 038-142-100 ต่อ 109

เทศบาลเมืองอ่างศิลา
